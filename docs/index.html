Make design the goal,
not what survives shipping.

When an AI agent writes code, it optimizes the goal it is handed. Give it a feature ticket and design quality becomes whatever falls out. aims hands the agent the design outcome as the goal — with the feature as a constraint it must satisfy — measures the result against one set of principles, and files the design knowledge beside the code so the next session continues instead of re-deriving.

Direct

Hand the Guide's design objective to a capable Worker, with the behavior attached as a constraint. Quality is built at construction time.

Measure

Score the returned design against the principles, feed the findings back for one revise round — never a gate, never coercion.

Remember

File insights and decisions as records co-located with the code. A later clean session reads them by navigating, not re-deriving.
