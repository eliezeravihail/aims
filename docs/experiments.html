Changing existing code

Validating the refactoring checklist

Six experiments test refactoring-principles.md and /aims-refactor on real adaptations — synthetic tasks, a real library (boltons: add TTL), a 3-step rot sequence, a cross-cutting 4-module capstone (multi-currency), and a continuity check — each measured by runnable oracles + existing test suites + blind before/after design review. Full write-up: refactoring-SYNTHESIS.md.

Correctness: parity

A capable model with no method got every adaptation correct and behavior-preserving — single-file or cross-cutting. On changes a strong model already handles, the method is not needed for correctness. Stated plainly, not hidden.

The edge is structural, and it grows

Under the before/after review, the aims arm improves at each step of a sequence (named single-owners, short functions) while no-method stays flat and denser. One change hides this; a sequence exposes it — the mechanism behind the historical rot.

On the record: in the cross-cutting capstone the plain arm edged aims on one point — aims left an existing reader (statement) incoherent under multi-currency. That miss produced a real fix (§6: re-trace an existing reader that now runs on the change's new data shape), and a re-run with the fix caught it. Consistency-over-dogma held throughout: on plain-style code aims did not impose value objects.
Reading the numbers

Protocol & confounds

What makes a run count

Two arms (aims vs a control) build the same product across staged reveals with a passive oracle; separate blind judges grade against the same inventory; every claim carries a reproduction or file:line.

Why no single grade is a verdict

±0.5 judge noise (the three checkout 8.5s are a tie) · maturity asymmetry inflates the marketplace margin · n = 1 per product, product-dependent.

On the record: an earlier run showed aims last on checkout. With operator prompt-anchoring removed and §2 rebalanced, it did not reproduce — aims tied checkout and led marketplace. Both corrections contributed; at n = 1 they don't separate.
