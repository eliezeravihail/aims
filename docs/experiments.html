03 · Experiments

Tested, and honest about it

Every experiment is a controlled, blind-judged comparison — an aims arm against a rival or a no-method control, graded by separate judges against the same fixed inventory. A single-arm demonstration is not an experiment.

The protocol

What makes a run count

Two arms, a hidden oracle

An aims arm and a control arm build the same product across staged reveals; only the current stage card is visible, and a passive oracle answers product questions without volunteering anything. Asking the right question is itself under test.

Blind, separate judges

Judges are not the Guide that built the arm and do not know which codebase is which. Design, product, and cost are three reports, never merged into one score; every load-bearing claim carries a reproduction or a file:line.

Full protocol: experiments/PROTOCOL.md. Pilots include navigation, continued-development, a container-run instance-segmentation annotator, aims-vs-OpenSpec, marketplace change-absorption, and the ledger continuation.

Read with care

Why no single grade is a verdict

Judge noise (±0.5)

One LLM judge per product; the same design has scored 0.5 apart with no qualitative disagreement. A 0.5 gap is inside the instrument's precision — the three checkout 8.5s are a tie.

Maturity asymmetry

Arms differ in artifact maturity, and it runs opposite ways per product. The marketplace margin is inflated by the aims arm being a fuller document — read it as "won the extension axis," not a quality gulf.

n = 1, product-dependent

One product, one judge, one build each. aims' rank depends on the product — strongest where change-absorption is the axis. The honest signal is the recurring shape, not a win tally.

A retraction, on the record. An earlier run showed aims last on checkout. When the operator's prompt-anchoring was removed and the principles rebalanced, that result did not reproduce — aims tied checkout and led marketplace. The lesson is filed too: prompt-anchoring by the operator biases both build and judge, so runs use neutral prompts. The full record is in experiments/single-pass-assessment-rerun.
