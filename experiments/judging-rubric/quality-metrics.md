# Scoring the design principles — moved

This scoring layer is no longer a separate document. There is **one measurement instrument**, and it now
ships with the method:
[`../../skills/aims-guide/references/measurement.md`](../../skills/aims-guide/references/measurement.md)
— one row per principle §1–§18, each scored 0–10 from binary sub-checks, with the severity table,
aggregation, and the two projections (the in-loop **fix-list**; the full profile for comparing designs).

The experiment records in this folder were graded with this instrument (earlier runs on the 0–4 band, later
runs on the 0–10 sub-check scale — each record states its scale). Having a separate "review" measurement and
a separate "grading" measurement was the divergence this consolidation removes (`../../decisions/0014`).

The fillable form and a worked example remain in [`assessment-form.md`](assessment-form.md).
